# Dos de carte rares — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Trois dos rares (Dorure or, Dorure iris, Holo) en sombre et en clair, jamais visibles avant le retournement dans le rituel.

**Architecture:** `PokeCard.vue` calcule une variante `data-back` (`neutral | gold | iris | holo`) à partir de `tier`, `shiny` et `secret`, et ne rend la couronne et le ✦ du dos que pour les variantes qui les portent. Les matières vivent dans `src/styles.css` sous `.pkc-back[data-back="…"]`, avec leur pendant `[data-theme="light"]`.

**Tech Stack:** Vue 3 SFC, Vitest, CSS dans `src/styles.css`.

**Spec:** `docs/superpowers/specs/2026-10-06-dos-rares-design.md`

## Global Constraints

- Avec `secret`, `data-back="neutral"` et aucune couronne ni ✦ dans le DOM du dos.
- Chaque variante a sa version claire ; tout texte du dos tient 4,5:1 sur son fond.
- Les reflets suivent `--px` / `--py`.
- Français, commentaires sur le pourquoi, pas de `<style>` dans les SFC, aucune dépendance.
- Chaque tâche finit sur `npm test` au vert et un commit (`Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`).

## Review Focus

- [ ] **Step 2: le gabarit** — dans `PokeCard.vue` :

```js
// Le dos dit la rareté une fois la carte connue, jamais avant : `secret` le force au neutre.
const backVariant = computed(() => {
  if (props.secret) return 'neutral'
  if (props.tier === 'l' && props.shiny) return 'holo'
  if (props.tier === 'l') return 'gold'
  if (props.shiny) return 'iris'
  return 'neutral'
})
```

Sur `.pkc-back` : `:data-back="backVariant"`. Ajouter `<div class="pkc-back-sheen"></div>` après `.pkc-back-rosace`. Remplacer `<span class="pkc-mark"><i>PR</i>·DEX</span>` par :

```html
      <span class="pkc-mark">
        <span v-if="backVariant === 'gold' || backVariant === 'holo' || backVariant === 'iris'" class="pkc-back-signs">
          <svg v-if="backVariant !== 'iris'" class="pkc-back-crown" width="22" height="22" viewBox="0 0 24 24" fill="currentColor" aria-hidden="true"><path d="M3 18h18l-1.6-10-4.7 4.2L12 5l-2.7 7.2L4.6 8z"></path></svg>
          <span v-if="backVariant !== 'gold'" class="pkc-back-star" aria-hidden="true">✦</span>
        </span>
        <span class="pkc-mark-word"><i>PR</i>·DEX</span>
      </span>
```

Le test existant attend `.pkc-mark` à texte `PR·DEX` : le viser désormais par `.pkc-mark-word`.

Run: `npm test` — Expected: PASS. Commit `feat(cartes): variante de dos selon la rareté, neutre tant que la carte est secrète`.
